# 暗狱回廊：逐暗旅人

一款基于 Qt 框架开发的回合制地牢 RPG 游戏。

## 游戏简介

在黑暗的地牢中，你将扮演一名勇敢的逐暗旅人，探索层层深入的地牢，击败怪物，收集装备，最终挑战强大的BOSS。

## 游戏特色

- **回合制战斗系统**：策略性的战斗体验，支持普通攻击、技能释放、道具使用和逃跑
- **随机地牢生成**：每层地牢随机生成，包含战斗房、宝箱房和BOSS房
- **角色养成系统**：升级自动提升属性，解锁新技能
- **道具与装备系统**：丰富的道具和装备，穿戴后实时更新属性
- **商店系统**：购买消耗品和装备，提升角色实力
- **多存档系统**：支持最多5个存档，方便随时保存进度
- **自动保存系统**：到达每层开始房间时自动保存

## 操作说明

### 主菜单
- **开始新游戏**：创建新存档，需要先输入存档名称和角色名称
- **读取存档**：选择已有存档继续游戏
- **删除存档**：删除不需要的存档
- **游戏说明**：查看详细的游戏玩法说明
- **退出游戏**：关闭游戏

### 地牢探索
- **方向按钮**：控制角色在地图上移动
- **进入下一层**：击败当前层BOSS后可进入下一层
- **使用道具**：打开背包使用道具
- **穿戴装备**：打开装备栏穿戴装备
- **卸下装备**：卸下已装备的物品
- **查看技能**：查看已解锁的技能
- **进入商店**：购买道具和装备
- **返回主菜单**：返回主界面

### 战斗界面
- **攻击**：普通攻击敌人
- **技能**：释放技能攻击敌人
- **道具**：使用背包中的道具
- **逃跑**：尝试逃离战斗（有失败概率）

## 开发环境

- **框架**：Qt 6.11.1
- **语言**：C++
- **编译器**：MinGW 64-bit
- **开发工具**：Qt Creator

## 编译运行

1. 使用 Qt Creator 打开 `dungeon-rpg.pro` 项目文件
2. 配置 Qt 开发环境（确保已安装 Qt 6.11.1 和 MinGW）
3. 点击构建按钮编译项目
4. 点击运行按钮启动游戏
